# Fidelity matrix

Generated by `node scripts/gen-fidelity.mjs` from `src/schemas/fields.json` and `src/presets/official.json`.

Evidence refers to the client source captured on 2026-10-22 (REA archive `js/*.js`, read-only reference, not shipped). AimLite re-implements each rule; no source code is included.

**Status of the whole engine:** all 96 fields are implemented, typed and range-checked (TypeScript and Rust), and all 27 official presets play to their end condition through the real engine in the automated tests. "Rule-compatible" means the recovered formulas and update order are reproduced; it does **not** make AimLite scores equal to website scores (field size, timer delivery, input events and rendering differ).

Global time-model differences (apply to every row): the simulation runs on fixed 61 Hz engine time with seconds and timeouts as scheduled events (ties: second timer → timeouts → tick → input); the source used `setInterval`/`setTimeout` wall-clock timers that drift. Hover is re-evaluated after every tick and every pointer sample (the source relied on DOM mouseover). A gap > 250 ms between updates cancels the run instead of catching up. Anti-cheat checks (page offset, hover time, radius tampering) and online features are not reproduced; the 25-clicks-in-2-s guard is an option for official presets.
